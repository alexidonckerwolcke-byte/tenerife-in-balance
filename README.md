# Tenerife in Balance

A short presentation about mass tourism in Tenerife and ways to support more sustainable tourism.

Open `index.html` in a browser to start. Use the navigation to move through the slides.

The campaign website has three presenter pages:
- `campaign.html` — the challenge and why it matters
- `campaign-solutions.html` — the six proposed changes
- `campaign-support.html` — supporting the project and responsible visitor actions
